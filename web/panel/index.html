Добавить устройство

Локальное превью доступно сейчас. Прошивка и подключение физического SmallTV по Wi-Fi ещё не готовы.

Создаст запись в вашем аккаунте для Storm Simulator. Превью использует сессию браузера и не отправляет heartbeat устройства.

Передайте код только своему программному клиенту для POST /api/v1/devices/enroll. Это не код привязки Telegram. Код разрешает зарегистрировать устройство на ваш аккаунт.

Закрытие вкладки не отменяет выданный код: он действует не более 5 минут. Для немедленной отмены используйте кнопку ниже.
