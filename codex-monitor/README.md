# Windows Codex Monitor для Storm OS

Зарезервировано для будущего агента на основном Windows-ноутбуке.
Реализации нет. Перед разработкой требуется проверить документированные события
установленной версии Codex CLI. Codex на Debian не переносится.

Серверная регистрация и отдельные ключи будущих агентов реализованы в backend:
[протокол идентичностей](../docs/agent-identities.md). Это не агент на Windows,
не heartbeat и не отслеживание задач Codex. Клиентские credentials нельзя хранить в Git.
