# Стиль устройства и виды часов

По запросу владельца от 11 ноября 2026 оформление разделено на независимые оси:

- Цветовая тема: BlackArch Red, Dark Blue, Purple, Light.
- Стиль устройства: Классический, Минимализм, Терминал, Орбита. Применяется ко всему дисплею, включая Tamagotchi, карточки экранов, курсы и уведомления.
- Вид часов: Обычный, Увеличенный (пропорции вытянуты по вертикали), Минуты под часами, Со стрелками. Формат 12/24 и секунды остаются независимыми.

В панели настройки сгруппированы заголовками; в боте — разделами «Часы», «Экран», «Оформление». Общий стиль расположен рядом с цветовой темой.

Добавочные API-поля `device_style` и `clock_layout` не переименовывают старое `clock_style`. Миграция 0017 копирует прежний стиль в общий, сохраняет кнопки бота и переводит старый экран `null` в `tamagotchi`. Миграция 0018 расширяет список экранов значением `markets`, сохраняя все столбцы и ограничения. Старое поле `clock_style` принимается для совместимости, новые интерфейсы используют новые поля. Null остаётся приватным питомцем владельца; отдельного пункта экрана больше нет.

Значок сети рядом с индикатором API использует `navigator.onLine`: обычный контур при доступной сети браузера, красный перечёркнутый при offline. Это не проверка радио Wi-Fi, интернета или физического устройства. API может быть недоступен при доступной сети. Реальная прошивка должна получать Wi-Fi состояние из сетевого драйвера.

На заглушке Codex расположен оригинальный контурный робот `>_`. Референс в запросе не был прикреплён; это временный авторский символ, не подтверждённое воспроизведение референса. Мониторинг и отдельный погодный экран пока сохраняют отметку заглушек.

## Курсы

Экран `markets` показывает BTC, ETH, TON в USD, затем USD/EUR в RUB. TON трактуется как Toncoin, не произвольный токен GRAMM. Источники: [CoinGecko simple price](https://support.coingecko.com/articles/1183079640-i-only-want-crypto-prices-e-g-btc-price-how-can-i-do-this) и [XML Банка России](https://www.cbr.ru/development/sxml/). Ключи не требуются в этой реализации; доступность публичного endpoint и лимиты поставщика не гарантируются.

API `/api/v1/markets` требует пользовательскую сессию. Кэш один на процесс, ограничен двумя группами. TTL крипто 5 минут, валют ЦБ 1 час, timeout источника 3 секунды, ограничение ответа 128 KiB. При отказе повтор не чаще TTL. Последние криптокурсы показываются не дольше часа, валюты — трёх суток; устаревшие данные отмечены `*`, недоступные — `—`. Дата официального курса ЦБ отображается отдельно, это не текущий биржевой курс. Нет обязательных подписок. Тесты используют синтетические ответы без сети.

Для просмотра: выбрать устройство в `/panel/`, сохранить оформление/вид часов/стартовый экран, открыть его превью и обновить Ctrl+F5. Backend после добавления миграций требует перезапуска.
