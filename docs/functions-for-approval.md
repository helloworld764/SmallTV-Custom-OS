# Storm OS — функции следующих пользовательских этапов

**Статус: предложение для согласования, реализация не начата.**
Документ не меняет TZ.md/AGENTS.md. Основание — требование владельца сначала
согласовать функции Tamagotchi, Storm Bot и расширения Storm Control Panel.
Общие обязательные функции взяты из ТЗ; конкретные удобства и игровой баланс
ниже предложены разработчиком. Их можно дополнить или изменить до реализации.

## Tamagotchi — серверный движок и экран устройства

| Блок | Предлагаемые функции |
|---|---|
| Питомцы | Общие Pixel, Byte, Glitch; Null доступен только аккаунту владельца системы; собственный питомец из изображения |
| Личные данные | Один активный питомец на аккаунт; состояние выбранных питомцев сохраняется раздельно, переключение не стирает прогресс; чужие данные недоступны |
| Состояние | Сытость, энергия и настроение от 0 до 100; время последнего ухода, сон/бодрствование; серверное время как источник истины |
| Уход | Кормить, играть, уложить спать, разбудить, посмотреть состояние; понятное объяснение временно недоступного действия |
| Время и сохранение | Расчёт прошедшего времени при обращении, без постоянного тяжёлого игрового цикла; сохранение в SQLite, рестарт не обнуляет питомца |
| Повторные действия | Идемпотентные команды, cooldown, транзакционная защита от двойного нажатия и параллельных запросов |
| Свой персонаж | Единый промпт из ТЗ, загрузка, проверка MIME/сигнатуры/размера/декодирования, нормализация и превью перед подтверждением; отклонённая загрузка не заменяет питомца |
| Отображение | На SmallTV отдельный экран; реальные шрифты/спрайты/анимации и память — после устройства; Null требует референса владельца |
| Удобства | Краткая сводка показателей, подсказка доступных действий, подтверждение смены образа; мягкая механика с восстановимыми показателями |

Предлагаемый начальный баланс (тоже требует согласования):

- Новый питомец: сытость 80, энергия 80, настроение 80.
- Бодрствование за час: сытость −4, энергия −3, настроение −2.
- Сон за час: энергия +20, сытость −2; настроение сохраняется.
- Кормление: сытость +20; игра: настроение +15, энергия −10, сытость −5.
- Кормить/играть можно в бодрствовании; для игры нужна энергия не меньше 10.
- Cooldown кормления/игры — по 60 секунд, смены сна — 10 секунд.
- Показатели ограничены 0–100; один расчёт отсутствия ограничен 24 часами,
  затем сервер фиксирует новое время. Уход доступен и после длительного перерыва.
- Прогресс первой игровой версии — сохранённые показатели, история ухода и
  собственные образы. Уровни/экономика/эволюция требуют отдельного решения.

Это стартовая модель для детерминированных тестов, не утверждённый геймдизайн.
Полноценная браузерная игра и социальные механики в этот этап не включены.

## Storm Bot — один общий Telegram-бот

| Блок | Предлагаемые функции |
|---|---|
| Меню | Устройство, Tamagotchi, Настройки, Статус, Справка |
| Привязка | Одноразовая привязка Telegram user ID к аккаунту, подтверждение, просмотр текущей привязки и безопасная отвязка; username не используется как право доступа |
| Устройства | Выбор своего устройства, последняя связь, UNKNOWN/ONLINE/STALE/OFFLINE; переключение экрана, яркость, тема и базовый стартовый экран |
| Честный результат | Различать «настройка сохранена на сервере» и «устройство подтвердило применение»; второе появится только с подтверждённым device-протоколом |
| Питомец | Просмотр, выбор, кормление, игра, сон/пробуждение; собственное изображение и выдача точного шаблона промпта из ТЗ через единый движок |
| Уведомления | Добровольная подписка на Codex/связь и игровые напоминания после появления соответствующего источника; дедупликация, cooldown и тихие часы |
| Удобства | Последнее выбранное устройство, быстрые кнопки ухода и яркости, кнопки «Назад»/«Обновить», ясные сообщения об ограничении частоты и устаревших данных |
| Безопасность | Проверка прав на каждой команде/callback, идемпотентность и rate limit; секреты и тексты Codex не пересылаются в статусных уведомлениях |
| Ошибки | Недоступный источник отображается как недоступный; запросы Telegram ограничены timeout/backoff, повторы не создают второе игровое действие |

По умолчанию рассылка выключена до согласия пользователя. После выключения
backend бот на нём также недоступен; обещания отправлять предупреждение из
неработающего процесса нет. До настоящего токена/аккаунта можно реализовать
доменную логику и тесты через тестовый Telegram-адаптер, явно обозначая его.

В этот этап не входят персональные Tamagotchi-боты, запуск заданий Codex из
Telegram, обязательные платные API и генерация картинок локальной LLM.

## Storm Control Panel — пользователь и администратор

Вход/выход, текущие настройки, защита черновика и превью уже работают.
Ниже — полный предлагаемый набор расширений, а не утверждение об их готовности.

| Блок | Предлагаемые функции |
|---|---|
| Устройства пользователя | Список/поиск/выбор своих устройств, понятные состояния связи и последняя отметка, имя устройства, программный мастер одноразовой привязки |
| Доступ устройства | Выпуск/отмена кода привязки, ротация и отзыв device-ключа с подтверждением; выданный ключ показывается один раз, не хранится в localStorage |
| Экран и оформление | Яркость, темы и стартовый экран (готово); далее порядок экранов, форматы часов, пользовательские цвета, безопасные обои/превью и настройка уведомлений |
| Погода и часы | Город, часовой пояс, формат времени, отметка свежести погоды; источник только после проверки бесплатных условий, кэш и понятные ошибки |
| Codex | Связь агента отдельно от исторического исхода задачи, список run и ограниченный журнал без содержимого заданий; регистрация/ротация/отзыв агентов; выбор источников уведомлений для устройства |
| Питомец | Карточка состояния, выбор образа, безопасная загрузка/подтверждение медиа; полноценная интерактивная браузерная игра остаётся отложенной |
| Пользовательские уведомления | Типы, длительность и тихие часы в допустимых границах; постоянный индикатор backend сохраняется |
| Удобства | Адаптивность телефона/ПК, пагинация/поиск, фильтр событий, понятные пустые состояния, восстановление после сети, признаки «сохранено»/«применено» и защита несохранённых изменений |
| Super Admin | Пользователи/роли, все устройства/агенты, отзыв доступа, ограниченный журнал действий/ошибок, состояние backend/источников; подтверждения опасных изменений |
| Эксплуатация | Просмотр сведений о резервировании и документированный безопасный CLI-процесс восстановления; реальные метрики Debian/служб подключаются отдельно после подготовки сервера |
| После SmallTV | Версия реальной прошивки, подтверждение применения настроек, безопасные аппаратные настройки/локальный Wi-Fi provisioning и доступные обновления только после проверки оборудования |

Серверный доступ не означает автоматического доступа к паролям Wi-Fi. Локальная
страница ESP остаётся отдельным небольшим аппаратным компонентом. Кнопки OTA,
питания, SSH/systemd и произвольная командная консоль в текущий план панели не входят.
Назначение прав и восстановление БД нельзя выполнять скрыто в фоне.

## Порядок после согласования

1. Зафиксировать выбранные функции и баланс, затем игровой движок с SQLite/API
   и автоматическими тестами, без Telegram-токена и реального SmallTV.
2. Расширить панель согласованными функциями регистрации/связи и источников,
   используя уже проверенные backend-контракты.
3. Подключить единый Storm Bot через готовые доменные операции; настоящий запуск
   Telegram — после локальных тестов и безопасного предоставления владельцем токена.
4. Медиа и оформление — отдельный этап после базовой игры; аппаратные ограничения
   и референс Null уточняются с владельцем до обещаний пригодности для прошивки.

Можно согласовать весь предложенный набор либо только первые пункты и перечислить
свои дополнения. До ответа новые функции этих трёх платформ не реализуются.
